## <img src="https://github.com/KrishBharadwaj5678/Divyatra/raw/main/readme/gifs/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
| -------------------------- | ----------------------------------------------------- |
| 🛕 Darshan Virtual | Explore experiências em 3D com divindades hindus |
| 🎧 Histórias Sagradas | Ouça histórias devocionais sobre a divindade selecionada |
| 🪔 Oferenda de Diya | Faça uma oferenda de diya durante sua experiência de darshan |
| 🌸 Oferenda de Flores | Adicione uma oferenda floral com um único clique |
| 🔔 Sons de Oração | Reproduza sons de sinos de templo e shankh |
| 🌐 Opções de Idioma | Alterne o idioma da experiência |
| 🥽 Suporte a AR | Visualize modelos de divindades em realidade aumentada em dispositivos compatíveis |
| 🎨 Design Imersivo | Desfrute de uma interface espiritual com animações e efeitos visuais atmosféricos |
| 📱 Experiência Responsiva | Use o site em computadores e dispositivos móveis |
