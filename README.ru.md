## <img src="https://github.com/KrishBharadwaj5678/Divyatra/raw/main/readme/gifs/features.gif" width="35"/> Возможности

| Возможность | Описание |
| -------------------------- | ----------------------------------------------------- |
| 🛕 Виртуальный даршан | Исследуйте 3D-опыт, посвящённый индуистским божествам |
| 🎧 Священные истории | Слушайте духовные истории о выбранном божестве |
| 🪔 Подношение дийя | Совершайте символическое подношение дийя во время даршана |
| 🌸 Цветочное подношение | Добавляйте визуальное цветочное подношение одним нажатием |
| 🔔 Молитвенные звуки | Включайте звуки храмовых колоколов и раковины шанкх |
| 🌐 Выбор языка | Переключайте язык интерфейса и опыта |
| 🥽 Поддержка AR | Просматривайте 3D-модели божеств в AR на поддерживаемых устройствах |
| 🎨 Иммерсивный дизайн | Погрузитесь в атмосферный духовный интерфейс с анимациями |
| 📱 Адаптивный интерфейс | Используйте сайт на компьютерах и мобильных устройствах |
