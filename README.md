## <img src="https://github.com/KrishBharadwaj5678/Divyatra/raw/main/readme/gifs/features.gif" width="35"/> Features

| Feature | Description |
| -------------------------- | ----------------------------------------------------- |
| 🛕 Virtual Darshan | Explore 3D experiences featuring Hindu deities |
| 🎧 Sacred Stories | Listen to devotional stories about the selected deity |
| 🪔 Diya Offering | Offer a diya during your darshan experience |
| 🌸 Flower Offering | Add a visual flower offering with one click |
| 🔔 Prayer Sounds | Play temple bells and shankh sounds |
| 🌐 Language Options | Switch the experience’s language |
| 🥽 AR Support | View deity models in augmented reality on supported devices |
| 🎨 Immersive Design | Enjoy a devotional interface with animations and ambient visuals |
| 📱 Responsive Experience | Use the website on desktop and mobile devices |
