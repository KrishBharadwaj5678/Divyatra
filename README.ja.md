## <img src="https://github.com/KrishBharadwaj5678/Divyatra/raw/main/readme/gifs/features.gif" width="35"/> 機能

| 機能 | 説明 |
| -------------------------- | ----------------------------------------------------- |
| 🛕 バーチャル・ダルシャン | ヒンドゥー教の神々を3Dで体験できます |
| 🎧 聖なる物語 | 選択した神様にまつわる信仰の物語を聴くことができます |
| 🪔 ディヤーのお供え | ダルシャン中にディヤーをお供えできます |
| 🌸 花のお供え | ワンクリックで花のお供えを追加できます |
| 🔔 祈りの音 | 寺院の鐘やシャンカの音を再生できます |
| 🌐 言語オプション | 体験中の言語を切り替えられます |
| 🥽 AR対応 | 対応デバイスで神様の3DモデルをARで表示できます |
| 🎨 没入型デザイン | アニメーションと雰囲気のあるビジュアルを備えた精神的なインターフェースを楽しめます |
| 📱 レスポンシブ対応 | デスクトップとモバイルデバイスの両方で利用できます |

```bash

```
